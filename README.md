# 💰 退休金雙向規劃工具 v2 (Retirement Planner)

這是一個專業且直覺的退休金規劃工具，採用 **「70/30 資產配置」** 邏輯，並支持 **「臨時大額支出」** 模擬，幫助您更精確地規劃未來的財務自由路徑。

---

## ✨ 最新功能亮點

### 1. 🛡️ 70/30 資產配置邏輯
- **70% 投資部位**：這部分資金會根據您設定的預期報酬率進行複利增值。
- **30% 現金部位**：保留在手中作為流動資金，不計算投資回報，模擬真實世界中的風險對沖與彈性操作。

### 2. 💸 臨時大額支出模擬
- 您可以設定在退休期間的某一年（例如第 10 年）有一筆額外的支出（如環遊世界、醫療準備金、購車）。
- 程式會自動計算這筆支出對後續幾十年複利與資產壽命的連鎖影響。

### 3. ⚖️ 雙向試算模型
- **正向試算**：輸入現有資金，推算「現在購買力」下，每月可安全提領的金額。
- **反向試算**：輸入理想生活費，反推需要準備的「總本金」或是需要達到的「投資報酬率」。

### 4. 📊 深度可視化
- **趨勢圖表**：直觀呈現資產餘額與提領金額的消長。
- **詳細明細表**：逐年拆解「年初資產」、「生活費」、「臨時支出」、「投資收益」以及「年底現金/投資水位」。

## 🛠 使用技術
- **Python 3.14+**
- **Streamlit**: 打造互動式 Web 介面
- **Pandas**: 數據處理與表格生成
- **NumPy & Financial Math**: 核心財務模擬算法

## 🚀 如何在本地執行

1. **複製專案**：
   ```bash
   git clone https://github.com/您的帳號/retirement-calculator.git
   cd retirement-calculator
   ```

2. **啟動 Conda 環境並安裝套件**：
   ```bash
   conda activate your_env_name
   pip install -r requirements.txt
   ```

3. **啟動程式**：
   ```bash
   streamlit run retirement_streamlit_app.py
   ```
