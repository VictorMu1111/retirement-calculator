# 💰 退休金雙向規劃工具 v6 (Retirement Planner)

這是一個專業且直覺的退休金規劃工具，採用 **「70/30 資產配置」** 邏輯，並支持 **「多筆臨時支出」** 與 **「勞保/勞退年金」** 模擬，幫助您更精確地規劃未來的財務自由路徑。

---

## 🎯 核心功能

### 🛡️ 資產配置：70/30 原則
- **70% 投資**：追求長期複利成長。
- **30% 現金**：保留流動性，應付市場震盪與生活突發狀況。

### 📈 投資組合：股票/債券雙引擎
- **股票**：高報酬、高波動，負責長期資本增長。
- **債券**：穩定現金流、低波動，負責降低整體風險。
- **比例可調**：您可以根據自己的風險承受度調整。
- **報酬分開設定**：股票與債券可分別設定預期年化報酬率。

### 🏦 勞保/勞退年金收入
- 台灣勞保老年年金法定請領年齡為 **65 歲**。
- 支援設定「退休年齡」與「勞保開始請領年齡」。
- 自動計算 **「社會保險空窗期」** ，這期間完全靠自己的資產累積。

### 💸 多筆臨時支出模擬
- 可以設定 **多筆** 不同年份的臨時支出（如醫療、旅遊、購車）。
- 每筆支出可獨立設定金額與發生年份。
- 可隨時新增或刪除支出項目。

### ⚖️ 雙向試算模型
- **正向試算**：輸入現有資金，推算「現在購買力」下，每月可安全提領的金額。
- **反向試算**：
  - 需準備多少本金？
  - 需達到多少投資報酬率？

### 📊 互動式圖表 (Plotly)
- **資產變化趨勢**：股票/債券/現金/總資產的逐年變化。
- **投資部位明細**：股票與債券的堆疊面積圖。
- **年度現金流**：生活費提領、社會保險收入、臨時支出的對比。

### 📋 年度詳細明細表
- 逐年拆解：年初資產、社會保險收入、生活費提領、臨時支出。
- 年底資產細分：股票部位、債券部位、現金部位。

## 🚀 如何在本地執行

### 1. 複製專案
```bash
git clone https://github.com/您的帳號/retirement-calculator.git
cd retirement-calculator
```

### 2. 建立 Conda 環境 (建議)
```bash
conda create -n retirement python=3.14
conda activate retirement
```

### 3. 安裝必要套件
```bash
pip install -r requirements.txt
```

### 4. 啟動程式
```bash
streamlit run retirement_streamlit_app.py
```
